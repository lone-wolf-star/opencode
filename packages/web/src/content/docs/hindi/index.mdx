[**OpenCode**](/) एक open source AI coding agent है। यह terminal-based interface, desktop app, या IDE extension के रूप में उपलब्ध है।

![OpenCode TUI with the opencode theme](../../assets/lander/screenshot.png)

आइए शुरू करते हैं।

---

#### आवश्यकताएँ

अपने terminal में OpenCode का उपयोग करने के लिए, आपको इन चीज़ों की आवश्यकता होगी:

1. एक modern terminal emulator, जैसे:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux और macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux और macOS

2. जिन LLM providers का आप उपयोग करना चाहते हैं, उनकी API keys।

## Install

OpenCode install करने का सबसे आसान तरीका install script है।

```bash
curl -fsSL https://opencode.ai/install | bash
```

आप इसे नीचे दिए गए commands के साथ भी install कर सकते हैं:

- **Node.js का उपयोग करके**

        <Tabs>

      <TabItem label="npm">
      ```bash
      npm install -g opencode-ai
      ```

          </TabItem>

        <TabItem label="Bun">
        ```bash
        bun install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="pnpm">
        ```bash
        pnpm install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="Yarn">
        ```bash
        yarn global add opencode-ai
        ```

      </TabItem>

  </Tabs>

- **macOS और Linux पर Homebrew का उपयोग करके**

  ```bash
  brew install anomalyco/tap/opencode
  ```

  > सबसे नवीन releases के लिए हम OpenCode tap का उपयोग करने की सलाह देते हैं। आधिकारिक `brew install opencode` formula को Homebrew team maintain करती है और यह कम बार update होता है।

- **Arch Linux पर install करना**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Stable)
  paru -S opencode-bin              # Arch Linux (Latest from AUR)
  ```

#### Windows

:::tip[Recommended: Use WSL]
Windows पर बेहतर अनुभव के लिए, हम [Windows Subsystem for Linux (WSL)](/docs/windows-wsl) का उपयोग करने की सलाह देते हैं। यह बेहतर performance और OpenCode की features के साथ पूर्ण compatibility देता है।
:::

- **Chocolatey का उपयोग करके**

  ```bash
  choco install opencode
  ```

- **Scoop का उपयोग करके**

  ```bash
  scoop install opencode
  ```

- **NPM का उपयोग करके**

  ```bash
  npm install -g opencode-ai
  ```

- **Mise का उपयोग करके**

  ```bash
  mise use -g github:anomalyco/opencode
  ```

- **Docker का उपयोग करके**

  ```bash
  docker run -it --rm ghcr.io/anomalyco/opencode
  ```

Windows पर Bun का उपयोग करके OpenCode install करने का support अभी प्रगति पर है।

आप binary को [Releases](https://github.com/anomalyco/opencode/releases) से भी प्राप्त कर सकते हैं।

## Configure

OpenCode के साथ आप किसी भी LLM provider का उपयोग उसकी API keys configure करके कर सकते हैं।

यदि आप LLM providers का उपयोग करने में नए हैं, तो हम [OpenCode Zen](/docs/zen) की सलाह देते हैं।
यह models की एक curated सूची है जिसे OpenCode team ने test और verify किया है।

1. TUI में `/connect` command चलाएँ, opencode चुनें, और [opencode.ai/auth](https://opencode.ai/auth) पर जाएँ।

   ```txt
   /connect
   ```

2. Sign in करें, अपनी billing details जोड़ें, और अपनी API key copy करें।

3. अपनी API key paste करें।

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

वैकल्पिक रूप से, आप अन्य providers में से एक चुन सकते हैं। [और जानें](/docs/providers#directory)।

## Initialize

अब जब आपने एक provider configure कर लिया है, तो आप उस project में जा सकते हैं जिस पर आप काम करना चाहते हैं।

```bash
cd /path/to/project
```

और OpenCode चलाएँ।

```bash
opencode
```

इसके बाद, नीचे दिया गया command चलाकर project के लिए OpenCode initialize करें।

```bash frame="none"
/init
```

यह OpenCode को आपके project का analysis करने और project root में एक `AGENTS.md` file बनाने में मदद करेगा।

:::tip
आपको अपने project की `AGENTS.md` file को Git में commit करना चाहिए।
:::

इससे OpenCode को project structure और उपयोग किए गए coding patterns समझने में मदद मिलती है।

## Usage

अब आप अपने project पर काम करने के लिए OpenCode का उपयोग करने के लिए तैयार हैं। इससे बेझिझक कुछ भी पूछें!

यदि आप AI coding agent का उपयोग करने में नए हैं, तो यहाँ कुछ examples हैं जो मदद कर सकते हैं।

---

### सवाल पूछें

आप OpenCode से codebase को समझाने के लिए कह सकते हैं।

:::tip
Project में files को fuzzy search करने के लिए `@` key का उपयोग करें।
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

यह तब उपयोगी होता है जब codebase का कोई हिस्सा ऐसा हो जिस पर आपने काम न किया हो।

---

### Features जोड़ें

आप OpenCode से अपने project में नई features जोड़ने के लिए कह सकते हैं। हालांकि, पहले उससे एक plan बनवाने की हम सलाह देते हैं।

1. **एक plan बनाएँ**

   OpenCode में एक _Plan mode_ है जो changes करने की उसकी क्षमता को बंद कर देता है और इसके बजाय यह सुझाव देता है कि feature को _कैसे_ implement किया जाएगा।

   इसे **Tab** key दबाकर चालू करें। इसका indicator आपको नीचे दाईं ओर दिखेगा।

   ```bash frame="none" title="Plan mode में switch करें"
   <TAB>
   ```

   अब आइए बताएँ कि हमें इससे क्या करवाना है।

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   आपको OpenCode को पर्याप्त details देनी चाहिए ताकि वह समझ सके कि आप क्या चाहते हैं। यह मदद करता है यदि आप उससे वैसे बात करें जैसे अपनी team के किसी junior developer से करते हैं।

   :::tip
   OpenCode को भरपूर context और examples दें ताकि वह आपकी आवश्यकता को अच्छी तरह समझ सके।
   :::

2. **Plan पर iterate करें**

   जब वह आपको एक plan दे दे, तो आप उसे feedback दे सकते हैं या और details जोड़ सकते हैं।

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   Prompt में images जोड़ने के लिए उन्हें terminal में drag and drop करें।
   :::

   OpenCode आपके दिए गए images को scan कर सकता है और उन्हें prompt में जोड़ सकता है। यह आप image को terminal में drag and drop करके कर सकते हैं।

3. **Feature बनवाएँ**

   जब आपको plan ठीक लगे, तो **Tab** key फिर से दबाकर वापस _Build mode_ में जाएँ।

   ```bash frame="none"
   <TAB>
   ```

   और उससे changes करने के लिए कहें।

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### Changes करें

ज़्यादा सीधे-सादे changes के लिए, आप OpenCode से बिना plan review किए सीधे build करने के लिए कह सकते हैं।

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

आपको यह सुनिश्चित करना चाहिए कि आप पर्याप्त detail दें, ताकि OpenCode सही changes कर सके।

---

### Changes undo करें

मान लीजिए आप OpenCode से कुछ changes करने को कहते हैं।

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

लेकिन फिर आपको लगता है कि यह वैसा नहीं है जैसा आप चाहते थे। आप `/undo` command का उपयोग करके changes **undo कर सकते हैं**।

```bash frame="none"
/undo
```

OpenCode अब किए गए changes को revert करेगा और आपका original message फिर से दिखाएगा।

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

यहाँ से आप prompt को थोड़ा बदलकर OpenCode से दोबारा कोशिश करने के लिए कह सकते हैं।

:::tip
कई changes undo करने के लिए आप `/undo` को कई बार चला सकते हैं।
:::

या आप `/redo` command का उपयोग करके changes **redo** भी कर सकते हैं।

```bash frame="none"
/redo
```

## Share

OpenCode के साथ आपकी conversations को [अपनी team के साथ share](/docs/share) किया जा सकता है।

```bash frame="none"
/share
```

यह current conversation का एक link बनाएगा और उसे आपके clipboard में copy कर देगा।

:::note
Conversations डिफ़ॉल्ट रूप से shared नहीं होती हैं।
:::

यह रहा OpenCode के साथ एक [example conversation](https://opencode.ai/s/4XP1fce5)।

कस्टम कमांड आपको एक प्रोम्प्ट निर्दिष्ट करने की अनुमति देते हैं जो TUI में execute होने पर चलेगा।

---

## कमांड फ़ाइलें बनाएं

`.opencode/commands/` डायरेक्टरी में markdown फ़ाइलें बनाएं:

```md
---
description: Run tests with coverage
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

Run the full test suite with coverage report.
```

कमांड का उपयोग करने के लिए `/` टाइप करें:

```bash
/test
```

---

## कॉन्फ़िगर

### JSON

अपने OpenCode कॉन्फ़िग में कमांड जोड़ें:

```json
{
  "command": {
    "test": {
      "template": "Run the full test suite with coverage report",
      "description": "Run tests with coverage"
    }
  }
}
```

### Markdown

- Global: `~/.config/opencode/commands/`
- Per-project: `.opencode/commands/`

---

## प्रोम्प्ट कॉन्फ़िग

### तर्क

`$ARGUMENTS` placeholder का उपयोग करके कमांड में तर्क पास करें:

```md
---
description: Create a new component
---

Create a new React component named $ARGUMENTS with TypeScript support.
```

### शेल आउटपुट

`!`command`` का उपयोग करके bash कमांड आउटपुट इंजेक्ट करें:

```md
---
description: Analyze test coverage
---

Here are the current test results:
!`npm test`
```

### फ़ाइल संदर्भ

`@` फ़ाइल नाम से फ़ाइलें शामिल करें:

```md
---
description: Review component
---

Review the component in @src/components/Button.tsx.
```

## विकल्प

### template

LLM को भेजा जाने वाला प्रोम्प्ट (आवश्यक)।

### description

कमांड का संक्षिप्त विवरण।

### agent

कौन सा एजेंट इस कमांड को execute करे।

### model

इस कमांड के लिए डिफ़ॉल्ट मॉडल ओवरराइड करें।

OpenCode VS Code, Cursor, या किसी भी IDE जो terminal का समर्थन करता है, के साथ इंटीग्रेट होता है।

---

## उपयोग

- **Quick Launch**: Mac पर `Cmd+Esc` या Windows/Linux पर `Ctrl+Esc` OpenCode खोलने के लिए
- **New Session**: Mac पर `Cmd+Shift+Esc` या Windows/Linux पर `Ctrl+Shift+Esc` नया session शुरू करने के लिए
- **Context Awareness**: स्वचालित रूप से अपना वर्तमान selection या tab share करें

---

## इंस्टॉल

VS Code में:

1. VS Code खोलें
2. Integrated terminal खोलें
3. `opencode` run करें - एक्सटेंशन स्वचालित रूप से install होगा

---

## समस्या निवारण

यदि एक्सटेंशन install नहीं होता:
- Integrated terminal में `opencode` चला रहे हैं यह सुनिश्चित करें
- IDE के लिए CLI install है (code, cursor, etc.)

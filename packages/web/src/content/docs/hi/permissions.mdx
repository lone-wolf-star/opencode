OpenCode यह तय करने के लिए `permission` कॉन्फ़िग का उपयोग करता है कि कोई दिया गया कार्य स्वचालित रूप से चले, आपसे पूछे, या ब्लॉक हो।

---

## कार्रवाई

प्रत्येक अनुमति नियम एक में resolve होता है:

- `"allow"` — अनुमति के बिना चलाएं
- `"ask"` — अनुमति के लिए पूछें
- `"deny"` — कार्रवाई ब्लॉक करें

---

## कॉन्फ़िगरेशन

वैश्विक रूप से अनुमतियाँ सेट करें:

```json
{
  "permission": {
    "*": "ask",
    "bash": "allow",
    "edit": "deny"
  }
}
```

---

## विस्तृत नियम

वस्तु सिंटैक्स के साथ विभिन्न कार्रवाई लागू करें:

```json
{
  "permission": {
    "bash": {
      "*": "ask",
      "git *": "allow",
      "npm *": "allow",
      "rm *": "deny"
    }
  }
}
```

---

## उपलब्ध अनुमतियाँ

- `read` — फ़ाइल पढ़ना
- `edit` — सभी फ़ाइल संशोधन
- `glob` — फ़ाइल globbing
- `grep` — सामग्री खोज
- `list` — डायरेक्टरी सूचीबद्ध करना
- `bash` — शेल कमांड चलाना
- `task` — सबएजेंट launch करना
- `webfetch` — URL fetch करना
- `websearch` — वेब खोज

---

## डिफ़ॉल्ट

यदि आप कुछ निर्दिष्ट नहीं करते, OpenCode permissive डिफ़ॉल्ट से शुरू होता है:

- अधिकांश अनुमतियाँ `"allow"` डिफ़ॉल्ट हैं
- `.env` फ़ाइलें डिफ़ॉल्ट रूप से deny हैं

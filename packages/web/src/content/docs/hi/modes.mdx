---
title: मोड
description: विभिन्न उपयोग के मामलों के लिए विभिन्न मोड।
---

:::caution
मोड अब `agent` विकल्प के माध्यम से कॉन्फ़िगर किए जाते हैं।
:::

मोड विभिन्न उपयोग के मामलों के लिए व्यवहार, टूल और प्रोम्प्ट को कस्टमाइज़ करने की अनुमति देते हैं।

---

## बिल्ट-इन

### Build

डिफ़ॉल्ट मोड, सभी टूल सक्षम।

### Plan

योजना के लिए प्रतिबंधित मोड:
- `write`: नई फ़ाइलें नहीं बना सकते
- `edit`: फ़ाइलें संशोधित नहीं कर सकता
- `bash`: शेल कमांड नहीं चला सकता

---

## स्विच करें

सत्र के दौरान Tab कुंजी से मोड स्विच करें।

---

## कॉन्फ़िगर

### JSON

```json
{
  "mode": {
    "build": {
      "tools": {"write": true, "edit": true, "bash": true}
    },
    "plan": {
      "tools": {"write": false, "edit": false, "bash": false}
    }
  }
}
```

### Markdown

- Global: `~/.config/opencode/modes/`
- Project: `.opencode/modes/`

OpenCode एक ओपन सोर्स AI कोडिंग एजेंट है।

---

## आवश्यकताएं

- आधुनिक टर्मिनल एमुलेटर (WezTerm, Alacritty, Ghostty, Kitty)
- LLM प्रोवाइडर के लिए API key

---

## इंस्टॉल

```bash
curl -fsSL https://opencode.ai/install | bash
```

Node.js से:
```bash
npm install -g opencode-ai
```

Homebrew से:
```bash
brew install anomalyco/tap/opencode
```

---

## कॉन्फ़िगर

1. `/connect` कमांड चलाएं, opencode चुनें
2. opencode.ai/auth पर जाएं
3. API key कॉपी करें और पेस्ट करें

---

## प्रारंभ करें

```bash
cd /path/to/project
opencode
/init
```

---

## उपयोग

- **प्रश्न पूछें**: कोडबेस समझने के लिए
- **फीचर जोड़ें**: Tab से Plan mode में जाएं, प्लान बनाएं, फिर Build mode में वापस जाएं
- **बदलाव करें**: सीधे बदलाव के लिए कहें
- **बदलाव पूर्ववत करें**: `/undo` या `/redo`

---

## शेयर

`/share` कमांड से बातचीत शेयर करें

[**OpenCode**](/) एक ओपन सोर्स AI कोडिंग एजेंट है। यह टर्मिनल-आधारित इंटरफेस, डेस्कटॉप ऐप, या IDE एक्सटेंशन के रूप में उपलब्ध है।

चलिए शुरू करते हैं।

---

## आवश्यकताएं

OpenCode को टर्मिनल में उपयोग करने के लिए, आपको चाहिए:

1. एक आधुनिक टर्मिनल एमुलेटर जैसे: WezTerm, Alacritty, Ghostty, या Kitty
2. LLM प्रोवाइडर के लिए API कीज़ जो आप उपयोग करना चाहते हैं।

---

## इंस्टॉल

OpenCode इंस्टॉल करने का सबसे आसान तरीका इंस्टॉल स्क्रिप्ट के माध्यम से है:

```bash
curl -fsSL https://opencode.ai/install | bash
```

Node.js का उपयोग करके:
```bash
npm install -g opencode-ai
```

macOS/Linux पर Homebrew से:
```bash
brew install anomalyco/tap/opencode
```

Arch Linux पर:
```bash
sudo pacman -S opencode
```

विंडोज़ पर Chocolatey से:
```bash
choco install opencode
```

---

## कॉन्फ़िगर

OpenCode के साथ आप किसी भी LLM प्रोवाइडर को उनकी API कीज़ कॉन्फ़िगर करके उपयोग कर सकते हैं।

यदि आप LLM प्रोवाइडर का उपयोग करने के लिए नए हैं, तो हम OpenCode Zen का उपयोग करने की सलाह देते हैं।

1. TUI में `/connect` कमांड चलाएं, opencode चुनें, और opencode.ai/auth पर जाएं।
2. साइन इन करें, अपना बिलिंग विवरण जोड़ें, और अपनी API कॉपी करें।
3. अपनी API पेस्ट करें।

---

## प्रारंभ करें

अब जब आपने एक प्रोवाइडर कॉन्फ़िगर किया है, तो उस प्रोजेक्ट पर जाएं जिस पर आप काम करना चाहते हैं:

```bash
cd /path/to/project
opencode
```

प्रोजेक्ट के लिए OpenCode प्रारंभ करें:

```bash
/init
```

यह OpenCode को आपके प्रोजेक्ट का विश्लेषण करने और प्रोजेक्ट रूट में एक `AGENTS.md` फ़ाइल बनाने के लिए कहेगा।

---

## उपयोग

अब आप अपने प्रोजेक्ट पर काम करने के लिए OpenCode उपयोग करने के लिए तैयार हैं। इससे कुछ भी पूछें!

### प्रश्न पूछें

आप OpenCode से कोडबेस समझाने के लिए कह सकते हैं:
```txt
How is authentication handled in @packages/functions/src/api/index.ts
```

### फीचर जोड़ें

आप OpenCode से अपने प्रोजेक्ट में नए फीचर जोड़ने के लिए कह सकते हैं। पहले इसे एक प्लान बनाने के लिए कहें।

Tab कुंजी का उपयोग करके Plan mode में स्विच करें, अपना प्लान बनाएं, और फिर Build mode में वापस स्विच करके बदलाव करें।

### बदलाव करें

सीधे बदलावों के लिए, पहले प्लान की समीक्षा किए बिना OpenCode से बनाने के लिए कहें।

### बदलाव पूर्ववत करें

`/undo` कमांड का उपयोग करके बदलाव पूर्ववत करें, या `/redo` से फिर से करें।

---

## शेयर

बातचीत शेयर करने के लिए `/share` कमांड का उपयोग करें। यह एक लिंक बनाएगा और क्लिपबोर्ड पर कॉपी करेगा।

---

## कस्टमाइज़

इसे अपना बनाने के लिए, थीम चुनना, कीबिंड्स कस्टमाइज़ करना, कोड फॉर्मेटर कॉन्फ़िगर करना, या कस्टम कमांड बनाना सुझाते हैं।

एजेंट विशिष्ट कार्यों और वर्कफ़्लो के लिए कॉन्फ़िगर किए जा सकने वाले विशेषज्ञ AI सहायक हैं।

:::tip
कोड का विश्लेषण करने के लिए Plan एजेंट का उपयोग करें।
:::

---

## प्रकार

OpenCode में दो प्रकार के एजेंट हैं: प्राथमिक एजेंट और सबएजेंट।

### प्राथमिक एजेंट

मुख्य सहायक जिनसे आप सीधे इंटरैक्ट करते हैं। Tab कुंजी से स्विच करें।

OpenCode दो बिल्ट-इन प्राथमिक एजेंट के साथ आता है: **Build** और **Plan**।

### सबएजेंट

विशेषज्ञ सहायक जो प्राथमिक एजेंट invoke कर सकते हैं।

OpenCode दो बिल्ट-इन सबएजेंट के साथ आता है: **General** और **Explore**।

---

## बिल्ट-इन

### Build

डिफ़ॉल्ट प्राथमिक एजेंट, सभी टूल सक्षम।

### Plan

योजना के लिए प्रतिबंधित एजेंट। `write`, `edit`, `bash` डिफ़ॉल्ट रूप से `ask` पर हैं।

### General

सामान्य-उद्देश्य, पूर्ण टूल एक्सेस।

### Explore

कोडबेस तेजी से खोजने के लिए read-only एजेंट।

---

## उपयोग

1. Tab कुंजी से प्राथमिक एजेंट स्विच करें।
2. @ mentioning से सबएजेंट invoke करें।

---

## कॉन्फ़िगर

JSON या markdown फ़ाइलों से एजेंट कॉन्फ़िगर करें।

```json
{
  "agent": {
    "build": {
      "mode": "primary",
      "tools": {"write": true, "edit": true, "bash": true}
    },
    "plan": {
      "mode": "primary", 
      "tools": {"write": false, "edit": false, "bash": false}
    }
  }
}
```

---

## विकल्प

- **description**: एजेंट का विवरण
- **temperature**: जवाबों की यादृच्छिकता
- **model**: उपयोग करने के लिए मॉडल
- **tools**: कौन से टूल उपलब्ध हैं
- **permission**: अनुमति नियंत्रण

---

## एजेंट बनाएं

```bash
opencode agent create
```

---

## उपयोग के मामले

- Build: पूर्ण विकास
- Plan: विश्लेषण और योजना
- Review: कोड समीक्षा
- Debug: जांच
- Docs: दस्तावेज़ीकरण

प्लगइन आपको OpenCode को विस्तारित करने की अनुमति देते हैं।

---

## प्लगइन उपयोग

### Local फ़ाइलें
- `.opencode/plugins/` - Project-level
- `~/.config/opencode/plugins/` - Global

### npm से
```json
{
  "plugin": ["opencode-helicone-session"]
}
```

---

## प्लगइन बनाएं

```js
export const MyPlugin = async ({ project, client, $, directory }) => {
  return {
    // Hooks
  }
}
```

---

## Events

- `session.idle`
- `file.edited`
- `tool.execute.before`
- `tool.execute.after`

---

## उदाहरण

### Notification
```js
if (event.type === "session.idle") {
  await $`osascript -e 'display notification "Done"'`
}
```

### Custom Tools
```ts
tool: {
  mytool: tool({
    description: "Custom tool",
    args: { foo: tool.schema.string() },
    async execute(args) { return "result" }
  })
}
```

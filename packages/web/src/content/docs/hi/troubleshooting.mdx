सामान्य समस्याओं के समाधान।

---

## TUI शुरू नहीं होता

- सुनिश्चित करें कि terminal truecolor support करता है
- नवीनतम OpenCode संस्करण का उपयोग करें

---

## API key काम नहीं करती

- `/connect` कमांड से credentials जोड़ें
- सुनिश्चित करें कि API key सही है

---

## मॉडल सूची खाली है

- credentials जोड़े गए हैं यह सुनिश्चित करें
- `opencode models --refresh` चलाएं

---

## धीमा प्रदर्शन

- कम контекст 使用 करने का प्रयास करें
- छोटे मॉडल का उपयोग करें

---

## फ़ाइलें नहीं मिल रही हैं

- सुनिश्चित करें कि आप सही directory में हैं
- LSP सर्वर चल रहा है यह सुनिश्चित करें

OpenCode Zen OpenCode टीम द्वारा परीक्षण और सत्यापित मॉडल की एक curated सूची है।

---

## शुरू करें

1. `/connect` कमांड चलाएं, opencode चुनें
2. opencode.ai/auth पर जाएं
3. API key कॉपी करें
4. `/models` से Zen मॉडल चुनें

---

## मॉडल

Zen में विभिन्न प्रदाताओं के कई मॉडल शामिल हैं:

- GPT 5.2 Codex
- Claude Sonnet
- Gemini Pro
- और भी बहुत कुछ

---

## क्यों Zen?

- परीक्षण किए गए: सभी मॉडल OpenCode के साथ काम करने के लिए परीक्षण किए गए हैं
- सत्यापित: टूल calling और code generation के लिए अनुकूलित
- अद्यतन: नए मॉडल जैसे ही उपलब्ध होते हैं जोड़े जाते हैं

OpenCode आपके GitLab CI/CD pipeline या GitLab Duo के माध्यम से आपके GitLab वर्कफ़्लो के साथ इंटीग्रेट होता है।

---

## GitLab CI

OpenCode एक नियमित GitLab pipeline में काम करता है।

```yaml
include:
  - component: $CI_SERVER_FQDN/nagyv/gitlab-opencode/opencode@2
    inputs:
      auth_json: $OPENCODE_AUTH_JSON
```

---

## GitLab Duo

GitLab comment में `@opencode` mention करें।

---

## उदाहरण

### Issue समझाएं

```
@opencode explain this issue
```

### Issue fix करें

```
@opencode fix this
```

### Merge request review करें

```
@opencode review this merge request
```

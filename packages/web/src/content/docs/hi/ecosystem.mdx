कम्युनिटी द्वारा OpenCode पर बनाए गए प्रोजेक्ट का संग्रह।

:::note
अपना OpenCode संबंधित प्रोजेक्ट इस सूची में जोड़ना चाहते हैं? PR भेजें।
:::

आप awesome-opencode और opencode.cafe भी देख सकते हैं।

---

## प्लगइन

| नाम | विवरण |
|-----|--------|
| opencode-daytona | Daytona sandboxes में स्वचालित OpenCode सत्र |
| opencode-helicone-session | Helicone session headers इंजेक्ट करें |
| opencode-devcontainers | Multi-branch devcontainer isolation |
| opencode-wakatime | Wakatime के साथ उपयोग ट्रैक करें |
| opencode-supermemory | सत्रों में persistent memory |

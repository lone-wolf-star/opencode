OpenCode enterprise नेटवर्क वातावरण के लिए standard proxy environment variables और custom certificates का समर्थन करता है।

---

## प्रॉक्सी

OpenCode standard proxy environment variables का सम्मान करता है।

```bash
# HTTPS proxy (अनुशंसित)
export HTTPS_PROXY=https://proxy.example.com:8080

# HTTP proxy
export HTTP_PROXY=http://proxy.example.com:8080

# Local server के लिए bypass proxy (आवश्यक)
export NO_PROXY=localhost,127.0.0.1
```

:::caution
TUI एक local HTTP server से communicate करता है। रूटिंग loops रोकने के लिए इस connection के लिए proxy bypass करें।
:::

---

## प्रमाणीकरण

यदि आपके proxy को basic authentication चाहिए:

```bash
export HTTPS_PROXY=http://username:password@proxy.example.com:8080
```

---

## कस्टम प्रमाणपत्र

यदि आपका enterprise custom CAs का उपयोग करता है:

```bash
export NODE_EXTRA_CA_CERTS=/path/to/ca-cert.pem
```

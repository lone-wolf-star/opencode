## TUI शुरू करें

```bash
opencode
```

## कमांड्स

- `opencode run "prompt"` - गैर-इंटरैक्टिव मोड
- `opencode serve` - HTTP सर्वर
- `opencode web` - वेब इंटरफ़ेस
- `opencode auth` - क्रेडेंशियल मैनेज
- `opencode models` - मॉडल सूची
- `opencode upgrade` - अपडेट

## फ्लैग्स

- `--continue, -c`: पिछला सत्र जारी रखें
- `--model, -m`: मॉडल चुनें
- `--port`: पोर्ट निर्दिष्ट करें

---
title: शेयर
description: अपने OpenCode बातचीत शेयर करें।
---

OpenCode का शेयर फीचर आपको सार्वजनिक लिंक बनाने की अनुमति देता है।

:::note
शेयर की गई बातचीत किसी के भी के लिए सार्वजनिक रूप से accessible है।
---

## कैसे काम करता है

जब आप बातचीत शेयर करते हैं, OpenCode:

1. आपके सत्र के लिए एक अद्वितीय सार्वजनिक URL बनाता है
2. बातचीत इतिहास sync करता है
3. बातचीत को शेयर योग्य लिंक के माध्यम से accessible बनाता है

---

## शेयरिंग

### मैन्युअल (डिफ़ॉल्ट)

```bash
/share
```

### ऑटो-शेयर

```json
{
  "share": "auto"
}
```

### अक्षम

```json
{
  "share": "disabled"
}
```

---

## अनशेयर करें

```bash
/unshare
```

---

## गोपनीयता

- केवल वही बातचीत शेयर करें जिसमें संवेदनशील जानकारी न हो
- शेयर करने से पहले बातचीत की समीक्षा करें
- सहयोग पूरा होने पर अनशेयर करें

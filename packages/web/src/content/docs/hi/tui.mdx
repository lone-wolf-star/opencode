TUI OpenCode का मुख्य इंटरफ़ेस है।

---

## शुरू करें

```bash
opencode
```

---

## कमांड्स

| कमांड | विवरण |
|--------|--------|
| `/init` | प्रोजेक्ट analyze करें और AGENTS.md बनाएं |
| `/models` | मॉडल चुनें |
| `/theme` | थीम चुनें |
| `/share` | बातचीत शेयर करें |
| `/undo` | बदलाव पूर्ववत करें |
| `/redo` | बदलाव फिर से करें |
| `/help` | मदद दिखाएं |
| `/connect` | API credentials जोड़ें |

---

## कीबिंड्स

- **Tab**: Primary agents/modes के बीच स्विच करें
- **Ctrl+x**: Leader key (डिफ़ॉल्ट)
- **Ctrl+c**: सत्र interrupt करें

---

## सत्र

- `/sessions`: सभी सत्र सूचीबद्ध करें
- **Ctrl+x n**: नया सत्र शुरू करें

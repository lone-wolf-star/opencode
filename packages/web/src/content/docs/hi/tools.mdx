title: टूल्स
description: OpenCode के साथ उपलब्ध टूल्स।
---

OpenCode में कई built-in टूल्स हैं जो LLM को आपके codebase के साथ काम करने में मदद करते हैं।

---

## बिल्ट-इन टूल्स

### फ़ाइल टूल्स

- **read**: फ़ाइल सामग्री पढ़ें
- **write**: नई फ़ाइलें बनाएं
- **edit**: मौजूदा फ़ाइलें संपादित करें
- **glob**: पैटर्न से फ़ाइलें खोजें
- **grep**: फ़ाइल सामग्री खोजें
- **list**: डायरेक्टरी सामग्री सूचीबद्ध करें

### शेल टूल्स

- **bash**: शेल कमांड चलाएं

### वेब टूल्स

- **webfetch**: वेब सामग्री fetch करें
- **websearch**: वेब खोज करें

### अन्य टूल्स

- **edit**: फ़ाइल संपादित करें
- **patch**: फ़ाइलों में patches apply करें
- **task**: सबएजेंट launch करें
- **skill**: स्किल लोड करें

---

## उपयोग

LLM स्वचालित रूप से appropriate tool का उपयोग करता है जब आप कोड के बारे में प्रश्न पूछते हैं या बदलाव करने के लिए कहते हैं।

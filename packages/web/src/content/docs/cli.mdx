OpenCode CLI default taur par [TUI](/docs/tui) start karta hai jab aap ise bina kisi arguments ke run karte hain.

```bash
opencode
```

Lekin CLI me additional commands bhi available hain jo is page me document kiye gaye hain. In commands ki madad se aap OpenCode ko programmatically interact kara sakte hain.

```bash
opencode run "JavaScript me closures kaise kaam karte hain explain karo"
```

---

### tui

OpenCode terminal user interface start karta hai.

```bash
opencode [project]
```

#### Flags

| Flag         | Short | Description |
| ------------ | ----- | ----------- |
| `--continue` | `-c`  | Last session continue kare |
| `--session`  | `-s`  | Specific session ID continue kare |
| `--fork`     |       | Continue karte waqt session fork kare |
| `--prompt`   |       | Custom prompt use kare |
| `--model`    | `-m`  | Provider/model format me model choose kare |
| `--agent`    |       | Agent select kare |
| `--port`     |       | Server listen karne ke liye port |
| `--hostname` |       | Server listen karne ke liye hostname |

## Commands

OpenCode CLI me niche diye gaye commands bhi available hain.

---

### agent

OpenCode ke agents manage karne ke liye command.

```bash
opencode agent [command]
```

---

### attach

Already running OpenCode backend server ke saath terminal attach karta hai. Yeh server `serve` ya `web` command se start hua hota hai.

```bash
opencode attach [url]
```

Isse aap remote OpenCode backend ke saath TUI use kar sakte hain.

Example:

```bash
# Backend server start kare
opencode web --port 4096 --hostname 0.0.0.0

# Dusre terminal me TUI attach kare
opencode attach http://10.20.30.40:4096
```

#### Flags

| Flag | Short | Description |
|-----|-----|-------------|
| `--dir` | | TUI start karne ka working directory |
| `--session` | `-s` | Session ID continue kare |

---

#### create

Custom configuration ke saath naya agent create karta hai.

```bash
opencode agent create
```

Yeh command aapko step‑by‑step guide karega jisse aap system prompt aur tools configuration ke saath agent bana sakte hain.

---

#### list

Available agents list karta hai.

```bash
opencode agent list
```

---

### auth

Providers ke credentials aur login manage karne ke liye command.

```bash
opencode auth [command]
```

---

#### login

OpenCode provider list ko [Models.dev](https://models.dev) se use karta hai. `opencode auth login` command se aap kisi bhi provider ke API keys configure kar sakte hain.

Credentials file:

```txt
~/.local/share/opencode/auth.json
```

Command:

```bash
opencode auth login
```

OpenCode start hone par credentials file aur environment variables se providers load karta hai.

---

#### list

Authenticated providers ki list show karta hai.

```bash
opencode auth list
```

Short version:

```bash
opencode auth ls
```

---

#### logout

Credentials file se provider remove karta hai.

```bash
opencode auth logout
```

---

### github

Repository automation ke liye GitHub agent manage karta hai.

```bash
opencode github [command]
```

---

#### install

Repository me GitHub agent install karta hai.

```bash
opencode github install
```

Yeh GitHub Actions workflow setup karta hai aur configuration process guide karta hai.

---

#### run

GitHub agent run karta hai (usually GitHub Actions me).

```bash
opencode github run
```

##### Flags

| Flag | Description |
|------|-------------|
| `--event` | GitHub mock event run kare |
| `--token` | GitHub personal access token |

---

### mcp

Model Context Protocol servers manage karta hai.

```bash
opencode mcp [command]
```

---

#### add

Configuration me MCP server add karta hai.

```bash
opencode mcp add
```

Yeh command local ya remote MCP server add karne me guide karega.

---

#### list

Configured MCP servers aur unki connection status list karta hai.

```bash
opencode mcp list
```

Short version:

```bash
opencode mcp ls
```

---

### models

Configured providers se available models list karta hai.

```bash
opencode models [provider]
```

Models format:

```txt
provider/model
```

Example:

```bash
opencode models anthropic
```

#### Flags

| Flag | Description |
|------|-------------|
| `--refresh` | models.dev se cache refresh kare |
| `--verbose` | Detailed output show kare |

---

### run

Prompt pass karke non‑interactive mode me OpenCode run karta hai.

```bash
opencode run [message..]
```

Example:

```bash
opencode run Explain Go me context ka use
```

---

### serve

API access ke liye headless OpenCode server start karta hai.

```bash
opencode serve
```

Yeh HTTP server start karta hai jo TUI ke bina OpenCode functionality provide karta hai.

---

### session

OpenCode sessions manage karta hai.

```bash
opencode session [command]
```

---

#### list

All sessions list karta hai.

```bash
opencode session list
```

---

### stats

Token usage aur cost statistics show karta hai.

```bash
opencode stats
```

---

### export

Session data JSON format me export karta hai.

```bash
opencode export [sessionID]
```

---

### import

JSON file ya OpenCode share URL se session import karta hai.

```bash
opencode import <file>
```

---

### web

Web interface ke saath headless OpenCode server start karta hai.

```bash
opencode web
```

---

### acp

ACP (Agent Client Protocol) server start karta hai.

```bash
opencode acp
```

---

### uninstall

OpenCode uninstall karta hai aur related files remove karta hai.

```bash
opencode uninstall
```

---

### upgrade

OpenCode ko latest ya specific version me upgrade karta hai.

```bash
opencode upgrade
```

## Global Flags

CLI me global flags bhi available hain.

| Flag | Short | Description |
|------|------|-------------|
| `--help` | `-h` | Help display kare |
| `--version` | `-v` | Version number print kare |

## Environment variables

OpenCode ko environment variables ke through configure kiya ja sakta hai.

| Variable | Description |
|---------|-------------|
| `OPENCODE_AUTO_SHARE` | Sessions automatically share kare |
| `OPENCODE_CONFIG` | Config file ka path |
| `OPENCODE_CONFIG_DIR` | Config directory path |
| `OPENCODE_DISABLE_AUTOUPDATE` | Auto update checks disable kare |
| `OPENCODE_SERVER_PASSWORD` | HTTP basic auth enable kare |

---

### Experimental

Yeh variables experimental features enable karte hain.

| Variable | Description |
|---------|-------------|
| `OPENCODE_EXPERIMENTAL` | All experimental features enable kare |
| `OPENCODE_EXPERIMENTAL_PLAN_MODE` | Plan mode enable kare |

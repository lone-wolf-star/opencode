OpenCode CLI default taur par bina kisi argument ke run karne par [TUI](/docs/tui) start karta hai.

```bash
opencode
```

Lekin yeh commands bhi accept karta hai jaise ki is page me document kiya gaya hai. Isse aap OpenCode ko programmatically bhi use kar sakte ho.

```bash
opencode run "JavaScript me closures kaise kaam karte hain explain karo"
```

---

### tui

OpenCode terminal user interface start karein.

```bash
opencode [project]
```

#### Flags

| Flag         | Short | Description |
| ------------ | ----- | ----------- |
| `--continue` | `-c`  | Last session continue kare |
| `--session`  | `-s`  | Continue karne ke liye session ID |
| `--fork`     |       | Session fork kare jab continue kare |
| `--prompt`   |       | Custom prompt use kare |
| `--model`    | `-m`  | Provider/model format me model select kare |
| `--agent`    |       | Kaunsa agent use karna hai |
| `--port`     |       | Port jis par listen kare |
| `--hostname` |       | Hostname jis par listen kare |

## Commands

OpenCode CLI me neeche diye gaye commands bhi available hain.

---

### agent

OpenCode ke agents manage karne ke liye.

```bash
opencode agent [command]
```

---

### attach

Already running OpenCode backend server ke saath terminal attach karein.

```bash
opencode attach [url]
```

Example:

```bash
opencode web --port 4096 --hostname 0.0.0.0

opencode attach http://10.20.30.40:4096
```

#### Flags

| Flag | Short | Description |
|-----|-----|-------------|
| `--dir` | | Working directory jahan se TUI start hoga |
| `--session` | `-s` | Continue karne ke liye session ID |

---

#### create

Custom configuration ke saath naya agent create kare.

```bash
opencode agent create
```

---

#### list

Available agents ki list dikhata hai.

```bash
opencode agent list
```

---

### auth

Providers ke credentials aur login manage karne ke commands.

```bash
opencode auth [command]
```

---

#### login

`opencode auth login` use karke kisi bhi provider ke API keys configure kar sakte ho.

```bash
opencode auth login
```

Credentials `~/.local/share/opencode/auth.json` me store hote hain.

---

#### list

Authenticated providers ki list dikhata hai.

```bash
opencode auth list
```

Short version:

```bash
opencode auth ls
```

---

#### logout

Provider se logout karta hai aur credentials remove karta hai.

```bash
opencode auth logout
```

---

### github

GitHub automation ke liye GitHub agent manage kare.

```bash
opencode github [command]
```

---

#### install

Repository me GitHub agent install kare.

```bash
opencode github install
```

---

#### run

GitHub agent run kare (usually GitHub Actions me).

```bash
opencode github run
```

---

### mcp

Model Context Protocol servers manage kare.

```bash
opencode mcp [command]
```

---

#### add

Configuration me MCP server add kare.

```bash
opencode mcp add
```

---

#### list

Configured MCP servers aur unki connection status dikhata hai.

```bash
opencode mcp list
```

Short version:

```bash
opencode mcp ls
```

---

### models

Configured providers se available models ki list.

```bash
opencode models [provider]
```

Example:

```bash
opencode models anthropic
```

---

### run

Prompt pass karke non-interactive mode me opencode run kare.

```bash
opencode run [message..]
```

Automation ya scripting ke liye useful.

Example:

```bash
opencode run Explain context in Go
```

---

### serve

Headless OpenCode server start kare API access ke liye.

```bash
opencode serve
```

---

### session

OpenCode sessions manage kare.

```bash
opencode session [command]
```

---

### stats

Token usage aur cost statistics show karta hai.

```bash
opencode stats
```

---

### export

Session data JSON format me export kare.

```bash
opencode export [sessionID]
```

---

### import

Session data JSON file ya share URL se import kare.

```bash
opencode import <file>
```

---

### web

Web interface ke saath headless OpenCode server start kare.

```bash
opencode web
```

---

### acp

ACP (Agent Client Protocol) server start kare.

```bash
opencode acp
```

---

### uninstall

OpenCode uninstall kare aur related files remove kare.

```bash
opencode uninstall
```

---

### upgrade

OpenCode ko latest version ya specific version me upgrade kare.

```bash
opencode upgrade
```

---

## Global Flags

CLI ke global flags:

| Flag | Short | Description |
|------|------|-------------|
| `--help` | `-h` | Help display kare |
| `--version` | `-v` | Version number print kare |
| `--print-logs` | | Logs stderr me print kare |
| `--log-level` | | Log level set kare |

---

## Environment variables

OpenCode environment variables se configure ho sakta hai.

Example variables:

| Variable | Description |
|----------|-------------|
| `OPENCODE_CONFIG` | Config file ka path |
| `OPENCODE_CONFIG_DIR` | Config directory ka path |
| `OPENCODE_DISABLE_AUTOUPDATE` | Automatic update checks disable kare |
| `OPENCODE_CLIENT` | Client identifier |
| `OPENCODE_SERVER_PASSWORD` | Server auth enable kare |

---

### Experimental

Yeh variables experimental features enable karte hain.

| Variable | Description |
|----------|-------------|
| `OPENCODE_EXPERIMENTAL` | Sab experimental features enable kare |
| `OPENCODE_EXPERIMENTAL_PLAN_MODE` | Plan mode enable kare |

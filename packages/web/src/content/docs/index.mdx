[**OpenCode**](/) एक open source AI coding agent है. यह terminal-based interface, desktop app, या IDE extension के रूप में उपलब्ध है.

![OpenCode TUI with the opencode theme](../../assets/lander/screenshot.png)

चलिए शुरुआत करते हैं.

---

#### आवश्यकताएँ

अपने terminal में OpenCode का उपयोग करने के लिए आपको यह चाहिए:

1. एक modern terminal emulator, जैसे:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux और macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux और macOS

2. जिन LLM providers का आप उपयोग करना चाहते हैं, उनके API keys.

## इंस्टॉल करें

OpenCode को इंस्टॉल करने का सबसे आसान तरीका install script है.

```bash
curl -fsSL https://opencode.ai/install | bash
```

आप इसे नीचे दिए गए commands से भी इंस्टॉल कर सकते हैं:

- **Node.js का उपयोग करके**

        <Tabs>

      <TabItem label="npm">
      ```bash
      npm install -g opencode-ai
      ```

          </TabItem>

        <TabItem label="Bun">
        ```bash
        bun install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="pnpm">
        ```bash
        pnpm install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="Yarn">
        ```bash
        yarn global add opencode-ai
        ```

      </TabItem>

  </Tabs>

- **macOS और Linux पर Homebrew का उपयोग करके**

  ```bash
  brew install anomalyco/tap/opencode
  ```

  > हम सबसे up-to-date releases के लिए OpenCode tap का उपयोग करने की सलाह देते हैं. आधिकारिक `brew install opencode` formula Homebrew team द्वारा maintain किया जाता है और कम बार update होता है.

- **Arch Linux पर इंस्टॉल करना**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Stable)
  paru -S opencode-bin              # Arch Linux (Latest from AUR)
  ```

#### Windows

:::tip[सिफारिश: WSL का उपयोग करें]
Windows पर सबसे बेहतर अनुभव के लिए, हम [Windows Subsystem for Linux (WSL)](/docs/windows-wsl) का उपयोग करने की सलाह देते हैं. यह बेहतर performance और OpenCode की features के साथ पूर्ण compatibility देता है.
:::

- **Chocolatey का उपयोग करके**

  ```bash
  choco install opencode
  ```

- **Scoop का उपयोग करके**

  ```bash
  scoop install opencode
  ```

- **NPM का उपयोग करके**

  ```bash
  npm install -g opencode-ai
  ```

- **Mise का उपयोग करके**

  ```bash
  mise use -g github:anomalyco/opencode
  ```

- **Docker का उपयोग करके**

  ```bash
  docker run -it --rm ghcr.io/anomalyco/opencode
  ```

Windows पर Bun का उपयोग करके OpenCode इंस्टॉल करने का समर्थन अभी प्रगति पर है.

आप binary को [Releases](https://github.com/anomalyco/opencode/releases) से भी डाउनलोड कर सकते हैं.

## कॉन्फ़िगर करें

OpenCode के साथ आप किसी भी LLM provider का उपयोग उनके API keys configure करके कर सकते हैं.

यदि आप LLM providers के उपयोग में नए हैं, तो हम [OpenCode Zen](/docs/zen) की सलाह देते हैं.
यह models की एक curated सूची है जिसे OpenCode team ने test और verify किया है.

1. TUI में `/connect` command चलाएँ, opencode चुनें, और [opencode.ai/auth](https://opencode.ai/auth) पर जाएँ.

   ```txt
   /connect
   ```

2. Sign in करें, अपनी billing details जोड़ें, और अपनी API key कॉपी करें.

3. अपनी API key पेस्ट करें.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

वैकल्पिक रूप से, आप अन्य providers में से भी किसी एक को चुन सकते हैं. [और जानें](/docs/providers#directory).

## प्रारंभ करें

अब जब आपने एक provider configure कर लिया है, तो आप उस project में जा सकते हैं
जिस पर आप काम करना चाहते हैं.

```bash
cd /path/to/project
```

और OpenCode चलाएँ.

```bash
opencode
```

अब नीचे दिया गया command चलाकर project के लिए OpenCode initialize करें.

```bash frame="none"
/init
```

यह OpenCode को आपके project का analysis करने और project root में एक `AGENTS.md` file बनाने के लिए कहेगा.

:::tip
आपको अपने project की `AGENTS.md` file को Git में commit करना चाहिए.
:::

यह OpenCode को project structure और इस्तेमाल किए गए coding patterns को समझने में मदद करता है.

## उपयोग

अब आप अपने project पर काम करने के लिए OpenCode का उपयोग करने के लिए तैयार हैं. निःसंकोच इसे कुछ भी पूछें!

यदि आप AI coding agent का उपयोग करने में नए हैं, तो नीचे कुछ उदाहरण दिए गए हैं जो मदद कर सकते हैं.

---

### सवाल पूछें

आप OpenCode से codebase को आपके लिए समझाने के लिए कह सकते हैं.

:::tip
Project में files को fuzzy search करने के लिए `@` key का उपयोग करें.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

यह तब मददगार होता है जब codebase का कोई हिस्सा ऐसा हो जिस पर आपने काम न किया हो.

---

### फीचर्स जोड़ें

आप OpenCode से अपने project में नए features जोड़ने के लिए कह सकते हैं. हालांकि, हम पहले इससे एक plan बनवाने की सलाह देते हैं.

1. **एक plan बनाएँ**

   OpenCode में एक _Plan mode_ है जो changes करने की इसकी क्षमता को disable कर देता है
   और इसके बजाय यह सुझाव देता है कि feature को _कैसे_ implement किया जाएगा.

   इसे **Tab** key से switch करें. इसका indicator आपको नीचे दाईं ओर दिखेगा.

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   अब इसे बताएँ कि आप क्या चाहते हैं.

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   आपको OpenCode को इतने विवरण देने चाहिए कि वह समझ सके कि आप क्या चाहते हैं. यह मदद करता है
   यदि आप इससे ऐसे बात करें जैसे आप अपनी team के किसी junior developer से बात कर रहे हों.

   :::tip
   OpenCode को पर्याप्त context और examples दें ताकि वह समझ सके कि आप क्या चाहते हैं.
   :::

2. **Plan पर iterate करें**

   जब यह आपको एक plan दे दे, तो आप उसे feedback दे सकते हैं या और details जोड़ सकते हैं.

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   Prompt में images जोड़ने के लिए उन्हें terminal में drag and drop करें.
   :::

   OpenCode आपके दिए गए किसी भी image को scan करके prompt में जोड़ सकता है. आप यह
   image को terminal में drag and drop करके कर सकते हैं.

3. **Feature बनवाएँ**

   जब आप plan से संतुष्ट हों, तो **Tab** key फिर से दबाकर _Build mode_ में वापस जाएँ.

   ```bash frame="none"
   <TAB>
   ```

   और उससे changes करने के लिए कहें.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### बदलाव करें

ज़्यादा सीधे-सादे changes के लिए, आप OpenCode से बिना plan review किए सीधे build करने के लिए कह सकते हैं.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

आपको यह सुनिश्चित करना चाहिए कि आप पर्याप्त detail दें ताकि OpenCode सही
changes करे.

---

### बदलाव वापस लें

मान लीजिए आपने OpenCode से कुछ changes करने को कहा.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

लेकिन बाद में आपको एहसास हुआ कि यह वैसा नहीं था जैसा आप चाहते थे. आप `/undo` command का उपयोग करके changes **वापस ले सकते हैं**.

```bash frame="none"
/undo
```

OpenCode अब आपके किए गए changes revert करेगा और आपका original message
फिर से दिखाएगा.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

यहाँ से आप prompt को tweak कर सकते हैं और OpenCode से फिर से कोशिश करने के लिए कह सकते हैं.

:::tip
आप कई changes वापस लेने के लिए `/undo` को कई बार चला सकते हैं.
:::

या आप `/redo` command का उपयोग करके changes **दोबारा लागू** कर सकते हैं.

```bash frame="none"
/redo
```

## साझा करें

OpenCode के साथ आपकी conversations को [आपकी team के साथ साझा](/docs/share) किया जा सकता है.

```bash frame="none"
/share
```

यह current conversation का एक link बनाएगा और उसे आपके clipboard पर copy कर देगा.

:::note
Conversations डिफ़ॉल्ट रूप से साझा नहीं की जाती हैं.
:::

यहाँ OpenCode के साथ एक [example conversation](https://opencode.ai/s/4XP1fce5) है.

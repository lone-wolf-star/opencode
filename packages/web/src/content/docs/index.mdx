[**OpenCode**](/) ek open source AI coding agent hai. Yeh terminal-based interface, desktop app, ya IDE extension ke form me available hai.

![OpenCode TUI with the opencode theme](../../assets/lander/screenshot.png)

Chaliye ab start karte hain.

---

#### Prerequisites

Terminal me OpenCode use karne ke liye aapko chahiye:

1. Ek modern terminal emulator jaise:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux aur macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux aur macOS

2. Un LLM providers ke API keys jinhe aap use karna chahte hain.

## Install

OpenCode install karne ka sabse easy tareeka install script use karna hai.

```bash
curl -fsSL https://opencode.ai/install | bash
```

Aap niche diye gaye commands se bhi install kar sakte hain:

- **Node.js use karke**

- **macOS aur Linux par Homebrew use karke**

  ```bash

  ```

  > Hum recommend karte hain ki aap OpenCode tap use karein taaki latest releases mil sakein. Official `brew install opencode` formula Homebrew team maintain karti hai aur thoda kam frequently update hota hai.

- **Arch Linux par install karna**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Stable)
  paru -S opencode-bin              # Arch Linux (Latest from AUR)
  ```

## Configure

OpenCode me aap kisi bhi LLM provider ko configure karke use kar sakte hain.

Agar aap LLM providers ke saath naye hain, to hum recommend karte hain ki aap [OpenCode Zen](/docs/zen) use karein. Yeh curated models ki list hai jo OpenCode team ne test aur verify ki hai.

1. TUI me `/connect` command run karein, opencode select karein, aur [opencode.ai/auth](https://opencode.ai/auth) par jayein.

   ```txt
   /connect
   ```

2. Sign in karein, billing details add karein, aur apni API key copy karein.

3. API key paste karein.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

Alternative taur par aap kisi aur provider ko bhi select kar sakte hain. [Aur jaanne ke liye dekhein](/docs/providers#directory).

## Initialize

Ab jab provider configure ho gaya hai, aap us project folder me navigate kar sakte hain jahan aap kaam karna chahte hain.

```bash
cd /path/to/project
```

Aur OpenCode run karein.

```bash
opencode
```

Uske baad project ke liye OpenCode initialize karne ke liye yeh command run karein.

```bash frame="none"
/init
```

Isse OpenCode aapke project ko analyze karega aur project root me `AGENTS.md` file create karega.

:::tip
Apne project ka `AGENTS.md` file Git me commit karna achha practice hai.
:::

Yeh OpenCode ko project structure aur coding patterns samajhne me madad karta hai.

## Usage

Ab aap OpenCode ko apne project par kaam karne ke liye use kar sakte hain. Aap usse kuch bhi pooch sakte hain.

Agar aap AI coding agent use karne me naye hain, to niche kuch examples diye gaye hain jo madad kar sakte hain.

---

### Questions poochna

Aap OpenCode se codebase explain karne ke liye keh sakte hain.

:::tip
Project me files search karne ke liye `@` key ka use karein.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
Authentication kaise handle ho raha hai @packages/functions/src/api/index.ts me?
```

Yeh helpful hota hai agar codebase ka koi part aapne khud nahi likha ho.

---

### Features add karna

Aap OpenCode se project me naye features add karne ko keh sakte hain. Lekin pehle usse ek plan banane ke liye kehna better hota hai.

1. **Plan create karein**

   OpenCode me ek _Plan mode_ hota hai jo changes karne ki ability disable kar deta hai aur sirf yeh suggest karta hai ki feature kaise implement hoga.

   Is mode me switch karne ke liye **Tab** key press karein.

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   Ab describe karein ki aap kya chahte hain.

   ```txt frame="none"
   Jab user ek note delete kare, to database me use deleted flag ke saath mark karna hai.
   Phir ek screen banani hai jo recently deleted notes dikhaye.
   Us screen se user note ko undelete ya permanently delete kar sake.
   ```

   OpenCode ko clear details dena important hai taaki woh sahi implementation samajh sake.

   :::tip
   OpenCode ko context aur examples dene se woh better result deta hai.
   :::

2. **Plan par iterate karein**

   Jab plan mil jaye, aap feedback de sakte hain ya extra details add kar sakte hain.

   ```txt frame="none"
   Is new screen ko ek design ke base par banana hai jo maine pehle use kiya hai.
   [Image #1] Is image ko reference ke roop me dekhein.
   ```

   :::tip
   Terminal me images drag aur drop karke prompt me add kar sakte hain.
   :::

   OpenCode images ko scan karke unhe prompt me include kar sakta hai.

3. **Feature build karein**

   Jab plan theek lage, **Tab** key dabakar _Build mode_ me wapas aayein.

   ```bash frame="none"
   <TAB>
   ```

   Phir changes karne ke liye keh dein.

   ```bash frame="none"
   Sounds good! Ab changes implement karo.
   ```

---

### Direct changes karna

Simple changes ke liye aap OpenCode se directly implementation karne ko keh sakte hain.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
/settings route me authentication add karna hai. Dekho /notes route me kaise implement hua hai aur same logic /settings route me apply karo.
```

Aapko enough detail deni chahiye taaki OpenCode sahi changes kare.

---

### Changes undo karna

Agar OpenCode ne kuch aise changes kar diye jo aap nahi chahte the:

```txt frame="none" "@packages/functions/src/api/index.ts"
@packages/functions/src/api/index.ts me function refactor kar do
```

Toh aap `/undo` command se changes revert kar sakte hain.

```bash frame="none"
/undo
```

OpenCode changes revert karega aur aapka original message phir se show karega.

```txt frame="none" "@packages/functions/src/api/index.ts"
@packages/functions/src/api/index.ts me function refactor kar do
```

Ab aap prompt modify karke phir try kar sakte hain.

:::tip
`/undo` ko multiple times run karke multiple changes revert kiye ja sakte hain.
:::

Agar chahein to `/redo` command se changes wapas bhi la sakte hain.

```bash frame="none"
/redo
```

## Share

OpenCode ke saath jo conversations hoti hain unhe aap apni team ke saath [share](/docs/share) kar sakte hain.

```bash frame="none"

```

Yeh current conversation ka link generate karke clipboard me copy kar dega.

Conversations default se share nahi hote.

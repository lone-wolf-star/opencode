[**OpenCode**](/) ek open source AI coding agent hai. Yeh terminal-based interface, desktop app, ya IDE extension ke form me available hai.

![OpenCode TUI with the opencode theme](../../assets/lander/screenshot.png)

Chaliye shuru karte hain.

---

#### Prerequisites

Terminal me OpenCode use karne ke liye aapko chahiye:

1. Ek modern terminal emulator jaise:
   - [WezTerm](https://wezterm.org), cross-platform
   - [Alacritty](https://alacritty.org), cross-platform
   - [Ghostty](https://ghostty.org), Linux aur macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux aur macOS

2. Un LLM providers ke API keys jinko aap use karna chahte ho.

## Install

OpenCode install karne ka sabse easy tarika install script use karna hai.

```bash
curl -fsSL https://opencode.ai/install | bash
```

Aap niche diye gaye commands se bhi install kar sakte ho:

- **Node.js ka use karke**


  > Hum recommend karte hain ki OpenCode tap use karein taaki aapko latest releases milte rahein. Official `brew install opencode` formula Homebrew team maintain karti hai aur thoda kam frequently update hota hai.

- **Arch Linux par install karna**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Stable)
  paru -S opencode-bin              # Arch Linux (Latest from AUR)
  ```

## Configure

OpenCode ke saath aap kisi bhi LLM provider ko use kar sakte ho by configuring unke API keys.

Agar aap LLM providers use karne me naye ho, to hum [OpenCode Zen](/docs/zen) use karne ki recommendation dete hain.
Yeh models ki curated list hai jo OpenCode team ne test aur verify ki hai.

1. TUI me `/connect` command run karein, opencode select karein, aur [opencode.ai/auth](https://opencode.ai/auth) par jayein.

   ```txt
   /connect
   ```

2. Sign in karein, billing details add karein, aur apna API key copy karein.

3. API key paste karein.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

Alternative: aap kisi aur provider ko bhi select kar sakte ho. [Learn more](/docs/providers#directory).

## Initialize

Ab jab provider configure ho gaya hai, to us project folder me navigate karein jahan aap kaam karna chahte ho.

```bash
cd /path/to/project
```

Aur OpenCode run karein.

```bash
opencode
```

Ab project ke liye OpenCode initialize karne ke liye yeh command run karein.

```bash frame="none"
/init
```

Isse OpenCode aapke project ko analyze karega aur project root me `AGENTS.md` file create karega.

:::tip
Aapko project ki `AGENTS.md` file ko Git me commit karna chahiye.
:::

Yeh OpenCode ko project structure aur coding patterns samajhne me madad karta hai.

## Usage

Ab aap OpenCode ko apne project par kaam karne ke liye use kar sakte ho. Aap usse kuch bhi puch sakte ho.

Agar aap AI coding agent use karne me naye ho, to yeh examples helpful ho sakte hain.

---

### Ask questions

Aap OpenCode se codebase explain karne ke liye bol sakte ho.

:::tip
Project ke files fuzzy search karne ke liye `@` key use karein.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
Authentication kaise handle ho raha hai @packages/functions/src/api/index.ts me?
```

Yeh helpful hota hai jab codebase ka koi part aapne khud nahi likha ho.

---

### Add features

Aap OpenCode ko project me naye features add karne ke liye bol sakte ho. Lekin pehle plan banwana better hota hai.

1. **Create a plan**

   OpenCode me ek _Plan mode_ hota hai jo changes karna disable karta hai aur sirf suggest karta hai ki feature kaise implement hoga.

   Is mode me switch karne ke liye **Tab** key press karein. Neeche right corner me indicator dikhega.

   ```bash frame="none" title="Switch to Plan mode"
   <TAB>
   ```

   Ab describe karein ki aap kya build karna chahte ho.

   ```txt frame="none"
   Jab user koi note delete kare to usse database me deleted mark karein.
   Fir ek screen banaye jo recently deleted notes dikhaye.
   Wahan se user note ko restore ya permanently delete kar sake.
   ```

   OpenCode ko enough details dena important hai taaki woh samajh sake ki aap kya chahte ho. Isse aise treat karein jaise aap team ke junior developer se baat kar rahe ho.

   :::tip
   OpenCode ko zyada context aur examples dena usse better samajhne me help karta hai.
   :::

2. **Iterate on the plan**

   Jab OpenCode plan de de, to aap feedback de sakte ho ya aur details add kar sakte ho.

   ```txt frame="none"
   Hum is screen ka design ek purane design jaisa banana chahte hain.
   [Image #1] Is image ko reference ke tarah use karein.
   ```

   :::tip
   Terminal me images drag and drop karke prompt me add ki ja sakti hain.
   :::

   OpenCode images ko scan karke prompt me include kar sakta hai.

3. **Build the feature**

   Jab plan sahi lage, to **Tab** key press karke _Build mode_ me wapas aayein.

   ```bash frame="none"
   <TAB>
   ```

   Aur usse changes implement karne ko bolein.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### Make changes

Simple changes ke liye aap directly OpenCode ko implementation karne ko bol sakte ho bina plan review kiye.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
/settings route me authentication add karna hai. Dekho kaise yeh /notes route me implement hai @packages/functions/src/notes.ts me aur same logic ko @packages/functions/src/settings.ts me apply karo.
```

Zyada detail dena important hai taaki OpenCode sahi changes kare.

---

### Undo changes

Maan lo aapne OpenCode ko kuch changes karne ko bola.

```txt frame="none" "@packages/functions/src/api/index.ts"
Kya tum @packages/functions/src/api/index.ts me function refactor kar sakte ho?
```

Lekin baad me lage ki yeh expected result nahi tha. Aap `/undo` command se changes revert kar sakte ho.

```bash frame="none"
/undo
```

OpenCode changes revert karega aur aapka original message wapas dikhayega.

```txt frame="none" "@packages/functions/src/api/index.ts"
Kya tum @packages/functions/src/api/index.ts me function refactor kar sakte ho?
```

Ab aap prompt modify karke phir try kar sakte ho.

:::tip
Multiple changes undo karne ke liye `/undo` multiple times run kar sakte ho.
:::

Ya phir `/redo` command se changes dobara apply kar sakte ho.

```bash frame="none"
/redo
```

## Share

OpenCode ke saath jo conversations hoti hain unhe aap [team ke saath share](/docs/share) kar sakte ho.

```bash frame="none"
/share
```

Yeh current conversation ka link create karega aur clipboard me copy karega.

:::note
Conversations default se share nahi hoti.

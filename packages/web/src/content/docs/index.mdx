[**OpenCode**](/) एक ओपन सोर्स AI कोडिंग एजेंट है। यह टर्मिनल-आधारित इंटरफ़ेस, डेस्कटॉप ऐप या IDE एक्सटेंशन के रूप में उपलब्ध है।

![OpenCode TUI with the opencode theme](../../assets/lander/screenshot.png)

आइए शुरुआत करें।

---

#### आवश्यकताएँ

टर्मिनल में OpenCode उपयोग करने के लिए आपको चाहिए:

1. एक आधुनिक टर्मिनल एमुलेटर, जैसे:
   - [WezTerm](https://wezterm.org), cross‑platform
   - [Alacritty](https://alacritty.org), cross‑platform
   - [Ghostty](https://ghostty.org), Linux और macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux और macOS

2. जिन LLM प्रदाताओं का आप उपयोग करना चाहते हैं उनके API keys।

## इंस्टॉल करें

OpenCode इंस्टॉल करने का सबसे आसान तरीका install script है।

```bash
curl -fsSL https://opencode.ai/install | bash
```

आप इसे निम्न कमांड्स से भी इंस्टॉल कर सकते हैं:

- **Node.js का उपयोग करके**

<Tabs>

<TabItem label="npm">

```bash
npm install -g opencode-ai
```

</TabItem>

<TabItem label="Bun">

```bash
bun install -g opencode-ai
```

</TabItem>

<TabItem label="pnpm">

```bash
pnpm install -g opencode-ai
```

</TabItem>

<TabItem label="Yarn">

```bash
yarn global add opencode-ai
```

</TabItem>

</Tabs>

- **macOS और Linux पर Homebrew का उपयोग करके**

```bash
brew install anomalyco/tap/opencode
```

> नवीनतम रिलीज़ के लिए OpenCode tap उपयोग करने की सलाह दी जाती है। आधिकारिक `brew install opencode` formula Homebrew टीम द्वारा maintain किया जाता है और कम बार अपडेट होता है।

- **Arch Linux पर इंस्टॉल करना**

```bash
sudo pacman -S opencode
paru -S opencode-bin
```

#### Windows

:::tip[Recommended: Use WSL]
Windows पर बेहतर अनुभव के लिए हम [Windows Subsystem for Linux (WSL)](/docs/windows-wsl) उपयोग करने की सलाह देते हैं।
:::

- **Chocolatey का उपयोग करके**


- **Scoop का उपयोग करके**


- **NPM का उपयोग करके**


- **Mise का उपयोग करके**


आप [Releases](https://github.com/anomalyco/opencode/releases) से binary भी डाउनलोड कर सकते हैं।

## कॉन्फ़िगर करें

OpenCode के साथ आप किसी भी LLM provider का उपयोग कर सकते हैं उनके API keys कॉन्फ़िगर करके।

यदि आप LLM providers के लिए नए हैं, तो हम [OpenCode Zen](/docs/zen) उपयोग करने की सलाह देते हैं।

1. TUI में `/connect` कमांड चलाएँ और opencode चुनें।

```txt
/connect
```

2. साइन इन करें, billing details जोड़ें, और API key कॉपी करें।

3. अपनी API key पेस्ट करें।

```txt
┌ API key
│
│
└ enter
```

## Initialize

अब जब आपने provider कॉन्फ़िगर कर लिया है, उस प्रोजेक्ट डायरेक्टरी में जाएँ जिस पर आप काम करना चाहते हैं।

```bash
cd /path/to/project
```

फिर OpenCode चलाएँ:

```bash
opencode
```

और निम्न कमांड से OpenCode को प्रोजेक्ट के लिए initialize करें:

```bash
/init
```

यह आपके प्रोजेक्ट को analyze करेगा और project root में `AGENTS.md` फ़ाइल बनाएगा।

:::tip
अपने प्रोजेक्ट की `AGENTS.md` फ़ाइल को Git में commit करना चाहिए।
:::

## उपयोग

अब आप OpenCode का उपयोग अपने प्रोजेक्ट पर काम करने के लिए कर सकते हैं।

---

### सवाल पूछें

आप OpenCode से codebase समझाने के लिए पूछ सकते हैं।

:::tip
प्रोजेक्ट की files खोजने के लिए `@` का उपयोग करें।
:::

```txt
How is authentication handled in @packages/functions/src/api/index.ts
```

---

### फीचर जोड़ें

आप OpenCode से नए features बनाने के लिए कह सकते हैं। पहले उससे एक plan बनवाना बेहतर होता है।

1. **Plan बनाएं**

Plan mode में OpenCode बदलाव नहीं करता बल्कि implementation का सुझाव देता है।

```bash
<TAB>
```

फिर बताएं कि आप क्या बनाना चाहते हैं।

```txt
When a user deletes a note, flag it as deleted in the database and create a screen to view and restore deleted notes.
```

2. **Plan पर iterate करें**

OpenCode के plan पर feedback दें या और विवरण जोड़ें।

3. **Feature बनवाएँ**

Build mode में वापस जाएँ:

```bash
<TAB>
```

और OpenCode से बदलाव करने के लिए कहें।

---

### बदलाव undo करें

अगर OpenCode ने गलत बदलाव कर दिए हों तो आप `/undo` कमांड से उन्हें revert कर सकते हैं।

```bash
/undo
```

और `/redo` से दोबारा लागू कर सकते हैं।

```bash
/redo
```

आप OpenCode के साथ हुई conversations अपनी टीम के साथ साझा कर सकते हैं।

```bash
/share
```

## Customize

अब आप OpenCode को अपनी पसंद के अनुसार customize कर सकते हैं—जैसे themes चुनना, keybinds बदलना, formatters कॉन्फ़िगर करना, custom commands बनाना, या OpenCode config के साथ प्रयोग करना।
